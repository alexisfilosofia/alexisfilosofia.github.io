# Portfolio description

## Project title

School Enrollment and Geospatial Analysis

## Short description

Quantitative and geospatial analysis of historical school enrollment records using Python, Pandas, visualization tools and mapping workflows.

## Extended description

This project analyzes school enrollment records through a combination of quantitative, temporal, demographic and geospatial methods. It includes annual enrollment trends, age distributions, course-level patterns, distance-to-school analysis, spatial concentration, and aggregate sociodemographic indicators.

The public version of the project is privacy-preserving: original datasets are not included, and the repository contains only sanitized notebooks, aggregated outputs and selected screenshots.
