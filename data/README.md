# Data availability

The original datasets are not included in this public repository.

The source files used in the original analysis may contain sensitive institutional or student-level information, including enrollment records, addresses, family or guardian information, and other personal data.

This public version includes:
- sanitized methodological notebooks;
- aggregated outputs;
- selected public-safe screenshots;
- documentation of the analytical workflow.

To reproduce the project with new data, use anonymized or synthetic datasets following the schema described in the notebooks.
