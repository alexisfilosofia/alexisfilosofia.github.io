# Screenshot guide

This folder contains selected public-safe screenshots extracted from the notebooks.

Recommended additional screenshots to add manually, after anonymization/generalization:

- `04_course_year_heatmap.png`: screenshot of the course-year heatmap table, if you want the README to show it as an image.
- `07_student_spatial_distribution.png`: anonymized or approximate point map.
- `08_student_spatial_density_heatmap.png`: spatial density heatmap.

Do not upload screenshots showing:
- student names;
- exact addresses linked to individuals;
- Google Drive paths;
- personal folders;
- row-level sensitive records.
