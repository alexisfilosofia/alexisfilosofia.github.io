Outputs

Analytical components

Component 1 · Cleaning pipeline

From raw spreadsheets to a consolidated dataset

The workflow reads several yearly spreadsheet files and converts them into one consistent analytical table. It normalizes column names, removes irrelevant unnamed fields, maps heterogeneous headings to canonical names, reconstructs dates when needed, converts numeric variables, and keeps source-file metadata for traceability.

The key idea is not only to clean the data, but to make every transformation auditable. For that reason, the workflow also generates mapping tables that document how each original column was interpreted.

Component 2 · Category normalization

Making inconsistent labels comparable

Historical or institutional records often use different labels for the same category. The workflow standardizes variants into a controlled set of canonical categories, making it possible to compare results across files and time periods.

This step is essential before producing grouped tables, heatmaps, bar charts, or time-based summaries, because small differences in spelling or formatting can otherwise create false categories.

Component 3 · Statistical summaries

Descriptive statistics and exploratory indicators

The analysis produces frequency tables, annual summaries, grouped distributions, descriptive statistics, histograms, boxplots, heatmaps, and stacked bar charts. These outputs help detect concentration patterns, dispersion, outliers, and changes across groups or periods.

The goal is to move from isolated records to interpretable aggregate patterns while keeping the analysis transparent and reproducible.

  • Indicators

Component 4 · Geospatial visualization

Map-based outputs for spatial interpretation

The geospatial part of the workflow standardizes location fields, geocodes usable entries, creates map layers, and exports interactive HTML visualizations. The public version links only to visual map outputs and avoids publishing raw source tables.

This component is useful for identifying spatial concentration, distance patterns, and territorial structure in a way that is easier to interpret than a spreadsheet alone.

Implementation examples

Representative Python logic

Example 1 · Column normalization

Standardizing field names

A reusable normalization function converts source column names into lowercase, accent-free, underscore-separated identifiers. This makes it easier to merge files that use different labels for the same field. 

def normalize_column(name):
    name = str(name).strip().lower()
    name = remove_accents(name)
    name = replace_non_alphanumeric_with_underscore(name)
    return collapse_repeated_underscores(name)

Example 2 · Consolidation

Combining multiple files

Each file is read, cleaned, tagged with its source, and appended to a list. The final dataset is created by concatenating all standardized tables. 

tables = []

for file in spreadsheet_files:
    df = read_spreadsheet(file)
    df = standardize_columns(df)
    df = add_source_metadata(df, file)
    tables.append(df)

consolidated = concatenate(tables)

Example 3 · Analytical table

Grouped summaries

Once the data is clean, grouped summaries can be generated by combining time, category, and quantitative variables. 

summary = (
    consolidated
    .groupby(["period", "category"])
    .size()
    .reset_index(name="frequency")
)
